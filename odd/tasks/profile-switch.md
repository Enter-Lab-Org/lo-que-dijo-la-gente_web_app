# Feature: profile-switch
Objective: Admin panel (ADMIN + OPERADOR) with a database question bank (questions, answers, categories) and a switchable game profile ("100 Tacones Dijeron", +18). Branch: profile-switch (from 52aa291).
Delivery: ask-on-risk (forecast ~1500 authored lines; chain strategy asked before any PR). Test runner: `npx vitest run`; build `npx next build`.

## Specs
- S1 "Modifica la seccion de usuarios y crea un Panel de Administracion donde  ADMIN y OPERADOR pueda entrar." New login-only section `admin` (tab "Administración") for ADMIN and OPERADOR; the user management moves inside it as a sub-section that only ADMIN sees (assumption: users stay ADMIN-only, as in admin-users S1). The desktop app (no login) never shows it.
- S2 "En este panel se puede elegir el perfil que se usara y agregar preguntas al banco de preguntas".
- S3 "Crea una entidad/Tabla donde el usuario pueda agregar Categorias de preguntas". Table `categories` (unique name). Panel: list, add, delete (assumption: delete leaves its questions without category).
- S4 "Agrega como entidad de la base de datos una tabla Preguntas. esta sera un banco de preguntas con una tabla relacionada" — "pregunta : String que permite almacenar la pregunta a mostrar en el tablero", "categoria : sera una relacion a la tabla Categoria", "perfil : si es +18 o default." Panel: list, add, delete (assumption: no edit yet).
- S5 "crea una tabla relacion para relacionar las respuestas a la pregunta con su puntaje." — "pregunta-id : id que relaciona a la tabla del banco de preguntas", "puntaje : puntos que el usuario operador defina, por default pon 10 si no se especifica la pregunta". Assumption: each row also stores the answer text and its order (an answer without text cannot be shown). 1..8 answers per question (board limit).
- S6 Profiles: "el administrador pueda elegir entre 2 perfiles, el default (como esta actualmente) y uno nuevo al que por el momento llamaremos 100 tacones dijeron" — "manten todo lo necesario para que pueda cambiar de nombre y de colores." Name, colors and question profile of each game profile live in one module (src/domain/profiles.js).
- S7 "cuando el usuario elija el perfil 100-Tacones(posterior cambio de nombre), implementa el estilo, la colorimetria y muestra en el banco de preguntas, todas las preguntas con perfil +18 con un checkbox para que el usuario elija las que va a usar en el juego." Style per 100-tacones-dijeron-presentacion.pdf: purple stage with sunburst, red marquee frame with bulbs, "PREGUNTA" pill, purple tiles with yellow number, cream revealed answers with red points, broken heels as strikes; palette Morado Noche #24093F, Morado Drag #4B1580, Violeta Brillo #7A2DC8, Rojo Labial #E8243C, Naranja Tacón #FF7A1A, Amarillo Reflector #FFC727, Rosa Lentejuela #FF4FA3, Turquesa Neón #1EC8B8, Crema Escenario #FFF3DC. Assumption: the default profile lists its own (default) questions with the same checkboxes.
- S8 "La app debe preguntar al usuario operado si desea elegir este perfil, si da que Si, haz switch a este perfil con todo el color como muestra el documento PDF y carga las preguntas seleccionadas por el operador a usar." In-app confirmation (no browser dialog); "No" changes nothing.
- S9 (L2) "la base de datos sera la fuente unica, pero al quedar configurado el perfil, toma las preguntas seleccionadas por el usuario y colocalas en local storage". Applying a profile replaces the local bank (`ldlg-banco`) with the selected questions and stores the profile + selection locally; the game keeps reading the local bank.
- S10 Server enforcement: every `/api/bank/*` request needs a live session whose role can open `admin` (401 / 403); mutations need same origin (403). Validation messages in Spanish.
